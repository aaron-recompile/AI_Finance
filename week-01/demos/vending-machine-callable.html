A smart contract is a vending machine you can call

Pick an item, then let a caller call buy(slot, coins). The coin goes in, the item drops out, change comes back — by one fixed public rule. A human wallet and another contract call it exactly the same way. That's the whole idea.

👛 You · EOA (human wallet)
coins: 20
buy(🥤, 5)
🤖 SnackBot · Contract (another machine)
coins: 20
buy(🥤, 5)

Same door for both. The machine can't tell — and doesn't care — whether a person or a program is calling. No login, no account, no permission list.

tray: (empty)
function buy(slot, coins):
  require(coins >= price[slot] && stock[slot] > 0)
  stock[slot] -= 1; give(slot); return coins - price[slot]
// public, fixed, same for every caller — no "owner" branch

Mental model: the machine just sits there exposing buy(). Anyone — you, a bot, a whole chain of other contracts — can call it, and it runs the identical math every time. Stacking these callable machines is composability (Week 3 flash loans exploit it; Weeks 4 & 6 attack & defend it).
