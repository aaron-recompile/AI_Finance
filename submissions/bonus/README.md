# Bonus — Put yourself on GitHub (extra credit)

Optional, easy points. The goal: learn the thing every developer lives in — **GitHub** and the
**pull-request workflow** — and leave your mark on the class repo. Do all three parts.

---

## Part 1 — Get on GitHub (5 min)
1. Create a GitHub account (if you don't have one yet).
2. **Follow the instructor:** [@aaron-recompile](https://github.com/aaron-recompile)
3. On this repo (**AI_Finance**), click **⭐ Star** and **Fork** (top-right of the page).
   - *Star* = a public bookmark that says "this was useful." *Fork* = your own copy to work in.

## Part 2 — Explore (2 min)
Browse the instructor's other **public** repositories and **⭐ Star any one** you find
interesting — there's *Bitcoin from scratch*, Taproot tools, x402 data APIs, and more.

## Part 3 — Put your work in the repo (the real skill)
Collect the code from your **previous homeworks** and submit it here through a **Pull Request** —
the standard way developers contribute to a shared codebase.

1. On **your fork**, create a folder: `submissions/bonus/<your-github-username>/`
2. Copy [`_TEMPLATE/README.md`](_TEMPLATE/README.md) into it and fill it in (a short index of your files).
3. Add your previous homework files (any week) into that folder.
4. Commit → push to your fork → open a **Pull Request** into `aaron-recompile/AI_Finance` → `main`.
   Title it: `bonus: <your-github-username>`.
5. The instructor reviews and **merges** it — now your name is a contributor on the repo.

---

## What you actually learn
- A GitHub **profile, follows, and stars** — how developers find each other and good work.
- **Fork → branch → commit → Pull Request → merge** — the universal open-source collaboration loop. You will use this at every job.

## Submit
The **Pull Request is your submission.** Make sure:
- your folder is exactly `submissions/bonus/<your-github-username>/`
- the PR targets `main`
- the title is `bonus: <your-github-username>`

**Due: by the Final.** Bonus / extra credit — fully optional.
